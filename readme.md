## 一、项目简介

UP主为了给拓竹P1S 3D打印机解决多色打印卡料问题，DIY了一个集成**称重、风扇、灯带和人体红外检测**的智能增高架，实现了打印任务的自动化控制

本项目基于 **ESP8266 (ESP-01 1M)** 开发，通过 **MQTT协议** 实现云端通信，支持微信小程序和Home Assistant远程控制。

---

## 二、技术架构

### 硬件平台

| 组件      | 型号/规格           |
| --------- | ------------------- |
| 主控芯片  | ESP8266 (ESP-01 1M) |
| 开发框架  | Arduino             |
| Flash大小 | 1MB                 |

### 引脚定义

| 引脚      | GPIO  | 功能                             |
| --------- | ----- | -------------------------------- |
| RelayPIN  | GPIO2 | 继电器控制（灯带开关）           |
| Relay2PIN | GPIO0 | 预留继电器                       |
| TXDPIN    | GPIO1 | 内部传感器检测（复用串口TX）     |
| RXDPIN    | GPIO3 | 外部人体传感器检测（复用串口RX） |

### 软件依赖

| 库名称           | 版本   | 用途             |
| ---------------- | ------ | ---------------- |
| ArduinoJson      | ^7.0.3 | JSON数据解析     |
| PubSubClient     | ^2.8   | MQTT客户端通信   |
| ESP8266WiFi      | 内置   | WiFi连接         |
| ESP8266WebServer | 内置   | HTTP OTA升级服务 |

## 三、制作流程

1. **背景介绍**：为迎接多色打印，解决料盘卡料问题，决定自制智控增高架
2. **功能设计**：称重、前后风扇、环绕灯带、联网远程控制、人体红外检测
3. **主控选择**：SP01S，利用4个小端口实现外部人体检测和内部打印动作检测
4. **实施步骤**：模型设计 → 代码开发 → 电路设计 → 硬件安装

## 四、MQTT通信协议

### 服务器配置

- **MQTT服务器**: `www.zhcmqtt.top`
- **端口**: 1883
- **客户端ID**: `3D_Print`

### 主题定义

| 主题            | 方向 | 说明                   |
| --------------- | ---- | ---------------------- |
| `3D_client/sub` | 发布 | 设备状态上报           |
| `Wechat/pub`    | 订阅 | 微信小程序控制指令     |
| `HA/3D_Control` | 订阅 | Home Assistant控制指令 |

### 数据格式

**上报数据 (JSON)**:

```json
{
  "info": { "name": "3D_Print" },
  "param": { "relay_pin": "on/off" }
}
```

**控制指令 (微信小程序)**:

```json
{
  "info": { "name": "Wechat", "time": "时间戳" },
  "equipment": { "switch1": "on/off" }
}
```

**控制指令 (Home Assistant)**: `on` 或 `off`

## 五、核心功能亮点

### 🔍 智能检测双保险

- **外部人体检测**：靠近打印机自动开灯，离开后延时关灯
- **内部打印检测**：实时监控打印状态，保障打印安全

### ☁️ 云端联动

- 通过TT上云功能实现云端通信
- 有打印任务时灯带自动开启，完成后延时关闭
- 支持云端下发指令控制

### 🔧 模块化预留

- 风扇功能预留安装位置
- 电路和机械结构支持后续升级

## 十、快速开始

### 环境准备

1. 安装 [PlatformIO IDE](https://platformio.org/install/ide)
2. 克隆或下载本项目

### 配置修改

复制 `include/config.example.h` 为 `include/config.h`，再填写本机网络。`include/config.h` 已在 `.gitignore` 中，不会进入仓库。

```cpp
#define WIFI_SSID "你的WiFi名称"
#define WIFI_PASSWD "你的WiFi密码"

IPAddress local_IP(192, 168, 1, 111);
IPAddress gateway(192, 168, 1, 1);
```

### 编译上传

```bash
# 编译
pio run

# 上传
pio run --target upload
```

### OTA升级

设备启动后，访问 `http://设备IP/update` 进行无线固件升级。
